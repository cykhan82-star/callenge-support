개인정보처리방침

운영자: 입슈톡 · 적용 대상: Callenge iPhone 앱 1.0
시행일: 2026년 10월 20일

운동 기록은 사용자의 기기에서 처리합니다.

입슈톡은 Callenge를 운영합니다. 현재 앱에는 회원가입, 광고, 추적, 분석 SDK, 외부 AI 전송, 운영자 서버와의 동기화 기능이 없습니다. 앱 이용을 위해 이름이나 건강 데이터를 입슈톡 서버로 보내지 않습니다.

1. 기기에서 처리하는 정보와 목적

  • 선택한 이름·성별·운동 목적: 화면의 호칭, 배경 및 운동 목표 설정에 사용합니다. 성별과 이름 입력은 선택 사항입니다.
  • 약속·주간 목표·직접 입력한 운동 종류·날짜·시간·메모·설정: 운동 타이머, 기록 조회, 주간 집계와 알림을 위해 저장합니다.
  • 건강에서 읽은 운동: 사용자가 연결을 선택하면 iOS 건강 접근 절차를 거쳐 최근 90일의 운동 종류·시작/종료 시각·운동 시간·기록 식별값을 읽습니다. 같은 기록의 중복 표시를 방지하고 운동 기록을 보여주는 데만 사용합니다. 건강 원본을 수정하거나 쓰지 않습니다. 심박, 혈압, 혈당, 수면, 위치를 요청하지 않습니다.
  • 건강에서 선택해 저장한 목표: 사용자가 선택한 운동 종류, 목표 횟수, 건강에서 선택했다는 표시를 저장합니다. 원본 건강 운동 식별값은 목표에 저장하지 않습니다.
  • 대화 입력: 기기 안에서 정해진 규칙에 따라 오늘 약속을 변경합니다. 외부 AI에 보내지 않으며 앱을 다시 실행하면 대화는 초기화됩니다. 마이크로 녹음하지 않습니다.

2. 보관과 보호

직접 입력한 기록과 설정은 iPhone 앱의 전용 저장 파일에 암호화합니다. 암호 키는 기기 전용 Keychain에 보관하고 기기 잠금 해제 상태에서 접근하도록 설정합니다. 저장 파일은 iOS 파일 보호를 적용하고 시스템 백업에서 제외합니다. 이전 개발 버전의 설정 저장소에 기록이 있는 경우 암호화 저장·재읽기 확인을 마친 뒤 이전 값을 삭제합니다. 기존에 사용자가 만든 파일이나 과거 시스템 백업까지 소급해 삭제하지는 않습니다.

건강에서 불러온 원본 운동 기록은 실행 중 메모리에만 두며 앱의 영구 저장소·내보내기 파일·운영자 서버에 저장하지 않습니다. 건강에서 선택해 저장한 운동 목표는 기기 기록에 포함됩니다.

3. 백업과 공유

설정의 데이터 관리에서 사용자가 직접 백업을 내보낼 수 있습니다. 백업에는 이름, 목표, 약속, 직접 기록, 메모, 설정 및 건강에서 선택해 저장한 목표가 포함됩니다. 원본 건강 운동 기록은 포함하지 않습니다.

내보내기는 사용자가 정한 12자 이상의 비밀번호로 암호화하며, 비밀번호는 저장하거나 운영자에게 보내지 않습니다. 비밀번호를 잊으면 입슈톡도 파일을 복구할 수 없습니다. 공유용 임시 파일은 공유 완료·취소 후 삭제하고, 중단되어 남은 파일은 다음 앱 실행 때 정리합니다. 사용자가 파일 앱이나 다른 서비스에 저장한 사본은 해당 위치에서 직접 관리·삭제해야 합니다. 선택한 서비스의 처리방침이 적용될 수 있습니다.

자동 계정 동기화나 서버 복구가 없으므로 기기를 바꾸거나 앱을 삭제하기 전에 필요한 기록을 암호화 백업으로 내보내 주세요.

4. 삭제·수정·권한 철회

기록 탭에서 직접 기록을 수정·삭제할 수 있으며, 설정 → 데이터 관리 → 저장 데이터 초기화에서 앱 기록과 설정을 초기화할 수 있습니다. 앱을 삭제하면 앱 영역의 기록이 삭제됩니다. 건강 앱 원본은 삭제되지 않습니다. iPhone의 건강 앱에서 Callenge의 읽기 접근을 변경하고, iPhone 설정에서 알림 권한을 끌 수 있습니다. 권한을 주지 않아도 약속·타이머·직접 기록 기능을 사용할 수 있습니다.

5. 외부 제공과 문의

앱이 운동·건강·대화 데이터를 광고, 마케팅, 데이터 판매 또는 외부 AI 처리 목적으로 제공하지 않습니다. 사용자가 선택한 파일 공유 외에는 앱 데이터를 외부로 전송하지 않습니다.

이메일로 문의하면 사용자가 보낸 이메일 주소, 본문 및 첨부파일을 문의 답변에 사용합니다. 문의는 선택 사항이며 처리에 필요한 동안만 보관하고 목적 달성 후 지체 없이 삭제합니다. 법령에 따라 보관해야 할 정보는 해당 의무 범위에서만 보관합니다. 민감한 운동 기록, 건강 정보, 백업 비밀번호는 문의에 첨부하지 마세요. 문의 자료의 열람·정정·삭제 요청은 아래 주소로 보내실 수 있습니다.

6. 웹 안내 페이지와 미리보기

이 공개 안내 사이트에는 별도 분석·광고·입력 폼·추적 스크립트를 넣지 않습니다. 사이트 제공자인 GitHub는 페이지 제공 및 보안을 위해 IP 등 기술 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요.

별도로 제공되는 웹 미리보기는 iPhone 앱과 다릅니다. 입력한 기록이 해당 브라우저의 localStorage에 암호화되지 않은 상태로 남을 수 있습니다. 브라우저 데이터를 지우면 삭제되며 기기 간 동기화되지 않습니다. 공용 기기에서 실제 개인 정보를 입력하지 마세요. 웹에서 내보내는 백업 파일에는 비밀번호 암호화를 적용합니다.

7. 변경 안내

처리 방식이나 기능이 바뀌면 이 페이지와 앱 안내를 갱신하고 시행일을 표시합니다. 새로운 건강 접근이나 외부 전송이 필요한 기능에는 사용 전에 적절한 안내와 선택 절차를 마련합니다.
